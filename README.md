# Fullstack Portfolio Application

A production-ready fullstack portfolio application designed to showcase projects, skills, and experience.  
Built with modern web technologies following real-world development practices.

---

## 🚀 Tech Stack

### Frontend
- Next.js (React)
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- Prisma ORM

### Database
- PostgreSQL

### Authentication
- JWT (JSON Web Tokens)

### DevOps & Tooling
- Docker (planned)
- GitHub Actions (CI/CD – planned)
- ESLint & Prettier
